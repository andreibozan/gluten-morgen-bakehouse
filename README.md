# Gluten Morgen Experience

Creează un website WordPress premium, complet responsive (mobile-first), pentru o brutărie artizanală numită „Gluten Morgen”, specializată în pâine cu maia naturală (sourdough). Designul trebuie să inspire calitate, tradiție, căldură și eleganță modernă, combinând stilul scandinav minimalist cu atmosfera unei brutării artizanale europene.

OBIECTIV:

Website-ul trebuie să transforme vizitatorii în clienți și să transmită ideea că fiecare pâine este făcută manual, cu răbdare și ingrediente naturale.
